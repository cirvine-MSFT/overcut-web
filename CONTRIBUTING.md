# Contributing

**This project does not accept external contributions.** Pull requests will be
closed unread. That is not a judgement about your code.

## Why

Every contributor owns the copyright in their contribution by default. Accepting
even one pull request without a Developer Certificate of Origin sign-off or a
Contributor Licence Agreement means Overcut can no longer be relicensed,
commercialised, or have its posture changed without tracking that person down and
obtaining their agreement.

That door is easy to keep shut now and expensive to close later, so it stays shut
until a contribution policy exists. The reasoning is recorded in full in the game
repository as `docs/decisions/0030-licensing-and-public-disclosure.md`,
decision 6.

This repository is public because a static website's source contains nothing
worth hiding and because GitHub Actions runners are free on public repositories —
not as an invitation to contribute.

## What is welcome

- **Bug reports.** If something on <https://overcut.racing> is broken, wrong, or
  inaccessible, open an issue. Describe what you saw, what you expected, and the
  browser and device.
- **Discussion.** The design of Overcut is deliberately discussed in public.
  Copyright protects expression, not ideas, and the conversation about what makes
  a collisionless racer work is one this project wants to have.

## Security

Do not open a public issue for a security problem. Contact the repository owner
directly through GitHub.
